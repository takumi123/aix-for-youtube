# どんなシステム？
ターゲット：スモールビジネスを行っている、小規模事業者、個人事業主が対象
ターゲットの悩み：クライアント集客

集客のために、Youtubeで情報発信を行うことが有効
しかし、今の仕事が忙しく時間が取れない。

忙しいスモールビジネスオーナーのために、1日15分でYoutubeの毎日投稿ができる。

マインドシェアを奪わない。

発信内容はYoutubeから取得して、分析をする。
さらに、あなたのSlackやGoogle Driveと連携し、ローカルデータを取得
↓
市場分析＋あなたのノウハウで、台本を作成。
台本を読み上げるだけ。

編集とアップロードは弊社が実施。
分析は生成AIが実施。

あなたは、毎日15分の作業をするだけで、Youtubeの毎日投稿ができ、集客ができる。
さらに、生成AIによって台本は更新。

問い合わせに最適化した形になる。

# ユーザータイプ

## 1. 動画投稿者（クライアント）
- スモールビジネスを行う事業者
- システムにログインして動画を撮影
- 台本を読み上げて録画
- 編集リクエストを送信
- 編集後の動画に対するフィードバックのみ可能

## 2. 動画編集者
- クライアントから送られた動画を編集
- 編集完了後、システムにアップロード
- アップロードされた動画は自動的にYoutubeに投稿
- クライアントとの直接コミュニケーションなし

# 動画編集者向け機能

## 1. 動画編集タスク管理
- クライアントから送られた未編集動画の一覧表示
- 編集中/完了済み動画のステータス管理
- 締切日管理
- 編集リクエスト内容の確認

## 2. 標準化された編集ガイドライン
- クライアント別の編集スタイルガイド
- 推奨エフェクト・トランジションのテンプレート
- 字幕・テロップの配置ルール
- ブランドカラー・フォント設定

## 3. 編集支援ツール
- よく使用するエフェクトのプリセット
- クライアント別のイントロ/アウトロテンプレート
- 自動字幕生成機能
- BGM・効果音ライブラリ

## 4. 動画アップロードワークフロー
- 編集済み動画のアップロード
- Youtube APIを使用した自動投稿
- サムネイル・タイトル・説明文のテンプレート
- 投稿スケジュール管理

## 5. フィードバック管理
- クライアントからのフィードバック確認
- フィードバックに基づく改善点の記録
- 編集スタイルガイドの自動更新

## 6. 品質管理システム
- 編集前チェックリスト
- 品質基準の自動チェック機能
- エラー検出ツール
- レビュー依頼システム



## 7. SNS連携機能
- Twitter APIを活用した情報収集
- トレンドキーワードの自動取得
- 関連ハッシュタグのモニタリング 
- 競合他社の動画コンテンツ分析
- 視聴者の反応やフィードバックの収集
- 人気コンテンツの特徴分析
- 最新の編集トレンド把握
