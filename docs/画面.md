# 画面一覧

## 会員管理系
- ログイン画面
- 会員登録画面（小規模事業者・個人事業主向け）
- マイページ
- プロフィール編集（事業内容、専門分野等）

## 管理画面
### トップ画面（15分で完結する動画撮影）
- Webカメラ撮影機能:ログイン後
  - ブラウザ上でカメラ起動
  - 台本表示機能
  - 録画開始/停止
  - プレビュー表示
  - 撮影データ自動保存
  - 編集依頼、コメント
  - 決済

### 過去動画一覧
- 撮影済み動画の一覧表示
- 動画のステータス確認（未編集/編集中/編集完了/アップロード済み）
- 弊社編集担当者とのコミュニケーション機能
- youtube分析データ


### 台本一覧
- 台本の一覧表示
- 台本のステータス確認（編集中/アップロード済み等）
- AIによる台本作成
 - 台本には何が改善されたか記載


### 設定画面
- アカウント設定
- Youtube連携
- Youtubeには公開/限定公開でアップロード
- メール通知設定
 - youtubeアップロード済み
 - 編集完了
- 支払い管理、請求書
